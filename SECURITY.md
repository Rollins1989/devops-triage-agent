# Security Policy

## Scope

This repository is a portfolio/demo system with a simulated infrastructure backend. It is not intended to be connected to production infrastructure without additional security review.

## Reporting a vulnerability

Please do not disclose sensitive credentials, production incident data, or exploit details in a public issue. Use GitHub's private vulnerability reporting flow for this repository when available.

## Safe defaults

- Remediation is dry-run by default.
- Tool access is restricted per agent.
- Reliability limits bound retries, loops, tool calls, and wall-clock time.
